ADVANTAGES AND APPLICATIONS

Advantages

1. Simple electronic circuit.
2. Low-cost components.
3. Automatic ON/OFF operation.
4. No microcontroller required.
5. Adjustable sensitivity.
6. Helps save electrical energy.

Applications

1. Automatic night lamps.
2. Home lighting systems.
3. Garden lighting.
4. Street lighting models.
5. Corridor lighting.
6. Outdoor lighting systems.

Future Improvements

- Using a higher-power LED for better illumination.
- Developing a compact PCB design.
- Improving the sensitivity adjustment circuit.
- Using an efficient power supply.
