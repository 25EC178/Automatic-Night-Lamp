COMPONENTS USED

Component| Function
LDR| Detects surrounding light intensity
Transistor| Acts as an electronic switch
LED| Produces light
Resistor| Limits current in the circuit
Potentiometer| Adjusts circuit sensitivity
DC Power Supply| Provides power to the circuit

Component Description

1. LDR: A light-sensitive resistor whose resistance changes according to the surrounding light.

2. Transistor: Controls the LED by acting as an electronic switch.

3. LED: Provides illumination when the circuit is activated.

4. Resistor: Helps control current flow and protects the components.

5. Potentiometer: Allows adjustment of the light detection sensitivity.
