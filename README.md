AUTOMATIC NIGHT LAMP

Project Overview

The Automatic Night Lamp is a simple electronic project designed to automatically control an LED based on the surrounding light intensity.

This project uses an LDR sensor to detect the light level. A transistor acts as an electronic switch to control the LED. A potentiometer is used to adjust the sensitivity of the circuit.

Components Required

- LDR (Light Dependent Resistor)
- Transistor
- LED (Light Emitting Diode)
- Resistors
- Potentiometer
- Connecting Wires
- DC Power Supply

Working Principle

The LDR detects the intensity of light in the surroundings. Its resistance changes depending on the amount of light falling on it.

When the surrounding light becomes low, the transistor switches ON and allows the LED to glow. During sufficient light conditions, the LED turns OFF.

The potentiometer is used to adjust the sensitivity of the circuit.

Features

- Automatic light detection
- No Arduino or microcontroller required
- Adjustable light sensitivity
- Simple and low-cost circuit
- Energy-efficient operation

Applications

- Home lighting systems
- Night lamps
- Automatic outdoor lighting
- Garden lighting
- Energy-saving lighting systems

Conclusion

The Automatic Night Lamp demonstrates the use of basic electronic components to achieve automatic lighting control. It helps reduce manual operation and saves energy by controlling the LED according to the surrounding light conditions.
